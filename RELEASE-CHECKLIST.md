- [x] source syntax checks;
- [x] unit tests;
- [x] CI workflow;
- [x] Pages workflow;
- [x] licences and citation;
- [x] privacy, accessibility, security, and contribution documents;

## Hardware/browser validation — manual

- [ ] M1 Max: cold procedural first paint;

- [ ] M1 Max: cached model load;
- [ ] Chrome and Edge procedural/hybrid;
- [ ] Firefox procedural fallback;
- [ ] Safari/macOS and Safari/iOS;
- [ ] Android Chrome;
- [ ] low-memory and WebGPU-unavailable fallback;
- [ ] keyboard and screen reader;
- [ ] external flash analysis;
- [ ] all downloaded export files opened in their target hosts.

## Account/registrar actions — manual

- [ ] choose public repository versus public deployment repository;
- [ ] make the selected repository public if required;
- [ ] enable GitHub Pages with GitHub Actions as source;
- [ ] verify the Pages URL;
- [ ] purchase the available canonical domain;
- [ ] configure the domain in Pages settings;
- [ ] create DNS records and HTTPS;
- [ ] configure the secondary domain as a redirect;
- [ ] create the first tagged release after validation.
