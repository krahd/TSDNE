Privacy

TSDNE generates, renders, evaluates, and hashes shaders locally. It uses no account, analytics, advertising, remote inference, language model, behavioural profile, or server-side generation.

Local anti-repetition memory

The browser stores a bounded set of non-reconstructive perceptual traces: a local random key, display time, broad family, and compact colour, luminance, spatial, and temporal descriptors.

It does not store source, seed, graph, hash, image, video, personal identity, dwell time, or preference labels. The system remembers enough not to repeat, but not enough to restore.

Provenance

Source and graph hashes exist only in active runtime memory and in a technical manifest when the visitor deliberately takes the code. No public registry or certificate is created.
