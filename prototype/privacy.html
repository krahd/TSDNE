Privacy and data flows

Procedural mode

TSDNE has no account, advertising, analytics, cross-site identifier, preference model, or server-side shader generation. The static host still receives ordinary requests for page assets and may retain infrastructure logs outside the control of the artwork.

Local encounter trace

A bounded record of what this browser was shown is stored in IndexedDB, with a limited local-storage fallback. It may include encounter identifiers, family, source signature, compact visual descriptors, and proposal provenance. This is a behavioural trace in the descriptive sense.

The trace is not uploaded by TSDNE, linked to an account, shared across sites, or interpreted as preference or taste. It can be cleared from about.

Optional local model

Local AI is off by default. Enabling it fetches a pinned WebLLM runtime from esm.run and model files from external model hosts. Those hosts receive ordinary request metadata such as IP address and user agent. The browser or runtime may cache downloaded files.

Inference runs on the visitor’s device through WebGPU. The compact shader-program description is not sent to a remote inference API. “Local” therefore describes inference location, not network-free or anonymous operation.

Local performance records

Generation and model timing records may be stored locally for diagnostics. They are not uploaded and can be cleared from about.

Limits

Local execution does not by itself establish complete privacy, ethical model provenance, low energy use, equal access, or freedom from upstream logging and supply-chain risk.
