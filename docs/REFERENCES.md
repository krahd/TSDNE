# Working references

This is a research ledger, not a finished bibliography. Venue and publication details must be verified before submission.

## Generative art and procedural systems

- Boden, Margaret A., and Ernest A. Edmonds. “What Is Generative Art?” *Digital Creativity* 20.1–2, 2009.
- Galanter, Philip. “What Is Generative Art? Complexity Theory as a Context for Art Theory.” *GA2003*, 2003.
- McCormack, Jon, and Mark d’Inverno, eds. *Computers and Creativity*. Springer, 2012.
- Shiffman, Daniel. *The Nature of Code*. Self-published/open web edition.
- Pearson, Matt. *Generative Art*. Manning, 2011.
- Greenberg, Ira. *Processing: Creative Coding and Computational Art*. Apress, 2007.
- Gonzalez Vivo, Patricio, and Jen Lowe. *The Book of Shaders*.
- ShaderToy. Browser platform for fragment-shader creation and sharing.
- LUMEN / lumenshaders. Browser-native WebGL2 generative shader system.

- Pugh, Justin K., Lisa B. Soros, and Kenneth O. Stanley. “Quality Diversity: A New Frontier for Evolutionary Computation.” *Frontiers in Robotics and AI* 3, 2016.

## AI shader and co-creative systems

- Ferrando, Santiago, Christian Clark, and Tomas Laurenzo. “Demokritos: Interactive, Community-Centred, Self-Improving Shader Generation using Large Language Models.” ISEA 2025.
- *AI Co-Artist*. EvoMUSART 2026, LNCS 16523, pp. 192–206. Verify full authorship and DOI before citation.
- ShaderGPT and AIShader project documentation. Verify archival and peer-reviewed status before citation.
- ShadAR. Verify final 2026 publication metadata before citation.

These sources define occupied technical space. They should not be used to frame TSDNE as the first LLM or browser shader generator.

## Synthetic “does not exist” culture

- *This Person Does Not Exist*. Website using StyleGAN-generated faces.
- Karras, Tero, Samuli Laine, and Timo Aila. “A Style-Based Generator Architecture for Generative Adversarial Networks.” CVPR 2019.
- Related “does not exist” sites and synthetic-media derivatives should be treated as cultural context rather than a coherent scholarly field.

- Ricci, Francesco, Lior Rokach, and Bracha Shapira, eds. *Recommender Systems Handbook*. Springer.
