# This Shader Does Not Exist

*This Shader Does Not Exist* (TSDNE) is a browser artwork about exploration, ephemerality, computational abundance, personal relation without ownership, and individualisation without surveillance.

The site presents one full-screen animated shader at a time. A visitor may remain with it, relinquish it for **another**, or choose **use this shader** and carry its freely reusable source elsewhere.

## Status

**Alpha prototype implemented.** The repository remains private while the artwork, licensing, browser support, accessibility, and public deployment are verified.

The current alpha combines an immediate procedural shader generator with an optional local WebLLM agent. The first image never waits for the model. On supported devices, a small model loads in the background and may later propose a constrained mutation to the current shader or to subsequent candidates.

## Artwork

TSDNE explores whether a computational object can be:

- personal without being behaviourally personalised;
- singular without an absolute guarantee of uniqueness;
- meaningful without exclusive ownership;
- freely circulating without becoming a marketplace;
- generated by AI without requiring accounts, profiling, API rent, or central prompt collection.

Refreshing is an irreversible wager: the visitor abandons the current shader without knowing whether the next will be preferable. A shader may disappear from the interface while continuing elsewhere as executable code.

## Alpha interaction

- **another** relinquishes the current shader and presents a new one;
- **use this shader** exports the GLSL source, typed graph, seed, lineage, and encounter record;
- **about** explains the artwork and current local-AI state;
- a restrained indicator shows whether the browser is procedural, loading the local model, ready, or applying a mutation.

The first shader appears procedurally. When the local model becomes ready, the visitor may click the indicator to invite it immediately. Otherwise, after sufficient dwell, the first shader may slowly change through one validated in-place mutation. Later hybrid candidates are prepared in the background.

## Architecture

1. Generate a cryptographically strong 128-bit seed in the browser.
2. Construct a typed shader graph from a curated visual family and normalised traits.
3. Emit conservative GLSL ES 3.00.
4. Compile and render candidates locally with WebGL2.
5. Reject coarse blank, static, excessively dark, excessively bright, or repetitive failures.
6. Show the first procedural shader immediately.
7. Load Qwen2.5 0.5B locally through WebLLM on capable devices.
8. Ask the model for a bounded JSON mutation over eight visual traits.
9. Validate, constrain, compile, render, and evaluate the proposal deterministically.
10. Preserve a complete procedural fallback when WebGPU, memory, network, or model loading is unavailable.

The AI is consequential but not sovereign. It proposes; deterministic systems decide whether the proposal can become visible.

## Privacy and data

The alpha uses no account, behavioural profile, cross-site identifier, advertising system, database, or server-side inference. Shader generation and model inference occur in the browser. WebLLM model artefacts are downloaded from their external model host and cached by the browser.

The alpha stores a bounded set of recent structural signatures in local browser storage to reduce obvious repetition on that device. This local history is not uploaded.

## Uniqueness

Cryptographic seeds make exact computational collisions negligibly probable, but different seeds or graphs may still produce similar appearances. TSDNE therefore distinguishes:

- **computational identity:** seed, graph, version, and source;
- **perceptual identity:** contingent visual resemblance;
- **encounter identity:** this visitor's relation to this shader at this moment.

TSDNE generates computationally distinct candidates and actively reduces recent perceptual repetition. It does not guarantee absolute global visual uniqueness.

## Run locally

The alpha is a static site with no build step or local dependencies.

```bash
cd prototype
python3 -m http.server 8080
```

Open `http://localhost:8080` in a WebGL2-capable browser. WebLLM additionally requires WebGPU. The first model load is large and may take substantial time; the procedural artwork remains usable throughout.

## Research and publication

The first planned paper is journal-first and practice-led:

> **Personal without Personalisation: Ephemerality, Relation, and Bespoke AI in *This Shader Does Not Exist***

It centres exploration, refreshing, contingent uniqueness, ephemerality, personal relation without property, local bespoke AI, and computational individualisation outside surveillance-based personalisation.

## Accessibility

The alpha supports keyboard-accessible controls and respects `prefers-reduced-motion` for interface transitions. A complete public release still requires formal review of animation speed, contrast, photosensitive-seizure risks, reduced-motion behaviour, screen-reader descriptions, and lower-power-device support.
