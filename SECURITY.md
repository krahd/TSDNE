# Security policy

TSDNE is a static browser artwork. It has no account system, application server, payment flow, or user database. Security reports remain relevant for client-side code execution, dependency loading, model artefacts, exports, and browser storage.

Report vulnerabilities privately to **tomas@laurenzo.net**. Do not include sensitive personal information. Relevant reports include code execution beyond shader/WebGL scope, dependency substitution, unsafe generated exports, persistent cross-site identifiers, or unexpected transmission of local encounter data.
