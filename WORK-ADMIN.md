# Cross-Repository Administration

Global repository registry, cross-domain status, and the master calendar are maintained in `krahd/tom-work-admin`.

This repository remains canonical for **This Shader Does Not Exist** as an artwork/research/software project: implementation, production audits, curation instrumentation and methodology, testing, reproducibility, and project-specific artistic/technical state.

Paper manuscripts and publication strategy remain canonical in `krahd/academic-writing/my_papers_2026/2026 - This Shader Does Not Exist/`.

A publication or submission outcome does not redefine the artwork/project's status. Propagate material cross-domain status/date changes to `tom-work-admin` while keeping substantive project state here.
